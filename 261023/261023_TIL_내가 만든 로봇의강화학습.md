CLI(씨엘아이): 명령줄 인터페이스 · check(체크): 검사 · train(트레인): 학습 · eval(이밸): 평가 · --config: 설정 파일 지정

#### 파일 생성과 Ubuntu 실행 명령 · 코드
```
cd "$HOME/rl_lab"
python3 -m venv .venv
.venv/bin/python -m pip install torch==2.14.1 \
  --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements.txt
cp assets/robot_config.template.json assets/robot_config.json
.venv/bin/python code/robot_rl.py check \
  --config assets/robot_config.json
.venv/bin/python code/robot_rl.py train \
  --config assets/robot_config.json \
  --steps 2048 --out runs/own-smoke
.venv/bin/python code/robot_rl.py train \
  --config assets/robot_config.json \
  --steps 100000 --out runs/own-ppo
.venv/bin/python code/robot_rl.py eval \
  --config assets/robot_config.json \
  --model runs/own-ppo/policy.zip --out runs/own-eval
.venv/bin/python -m tensorboard.main --logdir runs
.venv/bin/python -m pip freeze > installed-versions.txt
```

Rollout(롤아웃): 정책으로 수집한 경험 묶음 · Transition(트랜지션): 한 번의 상태 전이 자료
