
1. 개루프 제어 vs 폐루프 제어
   폐루프에는 개루프에 없는 퐈살표가 하나 있다 --> 되먹임(feedback)
   개루프 : 출력을 확인하지 않는다 --> 외란, 모델 올차에 무력
   폐루프 : 출력을 측정해 feedback하고, 오차만큼 계속 보정한다.
   
   시간이 조금 지났을때 얼마나 빠르게 속도가 변하는가
   미분 == 변화율
   위치를 미분 --> 속도
   속도를 미분 --> 가속도
   
   속도를 통해서 위치를 알 수 있는 것이 적분
   속도를 적분 --> 이동 거리
   적분은 초를 세분하게 쪼개서 
   
   엔코더에서 위치와 속도를 얻고 속도에서는 관절위치를 얻음
   Kv = 입력전압 당 힘
   라플라스 변환 이라는 것을 해야한다.(공식을 굳이 알 필요는 없음)
   
   센서 — 불필요해 저렴하고 단순   vs   필요해 비용 · 복잡도 증가
   외란 대응 — 오차가 그대로 남습니다   vs   자동 보정됩니다
   모델 오차 — 모델이 틀리면 결과도 틀립니다   vs   자동 보정됩니다
   안정성 — 문제 없음(대상이 안정하면)   vs   잘못 설계하면 발진 · 불안정
   대표 예 — 토스터 · 세탁기 타이머 · 스텝 모터   vs   에어컨 · 서보 · 드론 자세 제어
   
   폐루프가 항상 옳은 것은 아닙니다. 모델이 정확하고 외란이 없으며 센서 비용이 아가운 자리에는 개루프가 합리적인 선택입니다.
   
2. 전달함수
   모터의 식을 하나의 함수로 전달.
   **물리 법칙***
   *DC 모터에 전압을 걸면 속도가 어떻게 변하는가 — 전기식 + 뉴턴식**
   **J·dω/dt + b·ω = K·v(t)      (J 관성 · b 마찰 · K 토크 상수)**
   
   **라플라스**
   **미분 d/dt 를 s 곱하기로 바꿉니다 — 미분방정식이 대수식이 됩니다**
   **(J·s + b)·Ω(s) = K·V(s)**
   
   **전달함수**
   **입력의 라플라스 변환 대비 출력의 라플라스 변환의 비**
   **G(s) = Ω(s) / V(s) = K / (J·s + b)**
   
   모터든, 온도가 오르는 방이든, 물이 차는 탱크든 — 전달함수의 모양이 같으면
   반응하는 패턴도 같습니다. 그래서 대표 패턴 두 가지(1차 · 2차)만 깊이 익힙니다.
   
   
1. 두개의 응답
   
   G(s) = k(최종목적지)/ts +1
   T(dy/dt) + y = ku
   T(dy/dt) + y = k
   dy/dt = k-y/T
   현재위치에서 목표위치까지 남은 거리
   변화속도 비례 남은거리
   남은 거리가 낮으면 변화하는 속도가 낮아짐.
   
   시정수 τ 하나로 빠르기를 말할 수 있습니다
   초기 기울기를 그대로 연장하면 정확히 t = τ 에서 최종값과 만납니다 — 유용한 판독법입니다.
   
   로그의 speed 열이 y(t), 준 듀티가 입력입니다. 63% 지점의 시각이 τ, (최종 RPM ÷ 듀티)가 K.
   필수: 그래프에서 τ 를 읽고 5τ 면 도달을 판단한다
   
   모터토크가 발생해서 관절이 움직이면 관성에 의해서 목표위치보다 더 많이 간다.
   
   ωn(고유 진동수)은 “얼마나 빠른가”
   ζ(감쇠비)는 “얼마나 출렁이지 않는가”
   
   목표보다 얼마나 많이 움직였는지를 오버슈트(overshoot)
   정착시간 출렁임이 목표에 근사하게 머물기 시작하는 시각.
