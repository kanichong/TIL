고주파진동 - Kd게인이 너무 높으면 미래에 대한 변화가 큼


P 항: 힘의 크기에 비례 ( 현재 오차 )
I  항: 남아 있는 오차의 누적 ( 과거 오차 )
D 항: 오차가 변하는 속도 ( 미래 예측 )

u = Kpe + KiA + KdD
