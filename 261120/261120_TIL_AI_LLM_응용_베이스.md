CNN · 합성곱과 계층적 특징
CNN(Convolutional Neural Network): 작은 필터를 여러 위치에 적용하는 국소 연산과 가중치 공유

입력 영상  →  국소 패턴  →  조합 특징  →  클래스 점수

합성곱·비선형 변환의 반복으로 특징을 추출하고, 분류기에서 클래스별 점수를 계산합니다.
설명용 분류 확률: 상자 0.8 / 바닥 0.2
위치·3D 자세는 별도 출력이며, 집기 위치 추정에는 검출·깊이·좌표 변환이 추가로 필요합니다.

합성곱 · 출력 크기의 계산
출력 크기 = floor((N + 2P − K) / S) + 1   [dilation=1]
N: 입력 크기 / P: 패딩 / K: 필터 크기 / S: 이동 간격

32 + 2×1 = 34 (패딩 포함 입력)  →  34 − 3 = 31 (필터 시작점 범위)  →  31 / 1 + 1 = 32 (stride 반영·첫 위치 포함)

예: N=32, K=3, P=1, S=1 → floor((32 + 2 − 3) / 1) + 1 = 32
앞층은 단순 패턴, 뒤층은 조합 특징을 계산합니다.

합성곱 · 원소별 곱과 합산
입력 [[1,2],[3,4]]  ⊙  필터 [[1,0],[0,1]]  →  Σ  →  1×1 + 2×0 + 3×0 + 4×1 = 5
국소 영역과 필터의 대응 원소를 곱해 합산한 값 하나가 특징 맵의 한 위치에 대응합니다.
Stride: 이동 간격 / Padding: 가장자리 확장
일반적인 Conv2d는 필터를 반전하지 않는 교차상관 연산입니다.

ReLU·Pooling·Softmax · 연산 구분
연산  -  정의  -  역할  -  예
ReLU  -  max(0, x)  -  특징 변환  -  ReLU([-2, 3]) = [0, 3]
MaxPool  -  영역의 최댓값  -  공간 요약  -  MaxPool([[1, 4], [2, 3]]) = 4
Softmax  -  합이 1인 값으로 정규화  -  출력 정규화  -  클래스 점수 → 확률
분류기의 직접 출력은 클래스별 logit이며, CrossEntropyLoss의 입력은 일반적으로 softmax 이전 logit입니다.
