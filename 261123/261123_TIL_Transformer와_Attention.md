Transformer와 Attention
11강 · LLM · VLM · VLA Robotics · Q·K·V에서 causal Attention까지

Transformer · 토큰에서 벡터로
로봇은 ‘빨간 컵을 집어’라는 말을 어떻게 읽을까?
Transformer: 입력을 작은 단위로 나누고, 단위들 사이의 관계를 학습하는 모델

토큰 Token (처리할 조각)  →  토큰 ID (조각의 번호)  →  임베딩 Embedding (번호로 찾는 벡터)

예: ‘컵’이라는 조각에 ID 12가 붙었다면, 12번 행에서 [0.2, −0.1]을 꺼냅니다.
벡터는 숫자를 순서대로 모은 값이며, 토큰을 벡터로 바꾸면 모델이 곱셈과 덧셈으로 관계를 학습할 수 있습니다.

임베딩 · 토큰 ID가 벡터가 되는 과정
토크나이저가 문장을 부분 단어나 기호로 나누고, 각 토큰 ID로 임베딩 행렬의 한 행을 찾습니다.
임베딩 행렬 E의 선택 행 (설명용)
ID  -  벡터
ID 12  -  [0.2, −0.1]
ID 87  -  [0.7, 0.4]
같은 토큰은 같은 임베딩에서 출발합니다.
위치 정보를 더하면 A→B와 B→A의 순서를 구별할 수 있습니다.
여러 차원이 함께 토큰의 특징을 표현합니다.

Attention · Q·K·V의 직관
컵이 두 개라면 ‘컵’이라는 말만으로 고를 수 있을까? (탁자 위 빨간 컵 · 파란 컵, 지시 “빨간 컵을 집어”)
기호  -  질문  -  의미
Q  -  무엇을 찾을까?  -  ‘컵’을 설명할 단서
K  -  어디에 있을까?  -  각 단어가 가진 단서
V  -  무엇을 가져올까?  -  그 단어가 전하는 내용
모델은 단어를 숫자로 받으므로 ‘빨간’이 어느 컵을 가리키는지 관계를 학습해야 합니다.
‘컵’의 Q를 문장 속 K들과 비교 → ‘빨간’에 높은 점수가 나오면 그 단어의 V가 컵 표현에 더 많이 쓰입니다.

투영 · 왜 Wq를 곱할까?
‘컵’을 나타내는 일과 ‘컵을 설명해 줄 말을 찾는’ 일은 다릅니다. Wq는 컵의 숫자에서 두 번째 일에 쓸 단서를 뽑아냅니다.

X (지금 읽는 말 · 토큰마다 숫자 한 줄)  ×  Wq (배운 규칙 · 어떤 숫자를 어떻게 섞을까?)  =  Q (찾고 싶은 단서 · 다른 토큰의 K와 비교)

예: 컵의 한 줄 [2, 1] · 가중치 [3, −1] → 2×3 + 1×(−1) = 5 (비교에 쓸 숫자 하나)
처음에는 어떤 조합이 도움이 될지 모르며, 훈련 예제를 풀면서 예측 오차가 줄어드는 쪽으로 Wq를 조금씩 고칩니다.

투영 · 같은 입력에서 Q·K·V를 만드는 이유
투영  -  계산  -  각 행의 역할  -  쓰이는 단계
Query  -  Q = XWq  -  현재 위치가 찾는 특징  -  점수 계산
Key  -  K = XWk  -  비교할 위치의 특징  -  점수 계산
Value  -  V = XWv  -  출력에 전달할 내용  -  가중합
W는 학습으로 정한 가중치 행렬이며, 첨자 q·k·v는 각각 질의·키·값을 만드는 변환을 구분합니다.

Attention · 점수에서 섞는 비율로
내적: 같은 자리의 숫자끼리 곱해 더하는 계산 → Q와 K가 얼마나 잘 맞는지 점수로 나타냅니다.

내적과 스케일 조정 [1, 0] ÷ √2  →  softmax · 비율 변환 (약 67%와 33%)  →  가중합 · 정보 섞기 (0.67v₁ + 0.33v₂)

학습된 Wq는 새 문장을 읽을 때도 그대로 쓰며, 67%는 지금 입력한 두 토큰을 비교해서 나온 값입니다.
softmax: 점수가 큰 위치에 더 큰 비중을 주면서 한 행의 비중 합을 1로 맞춥니다.

손계산 · 두 토큰의 Attention
q = [1, 0], k₁ = [1, 0], k₂ = [0, 1]
내적 [1, 0] → √2로 나누면 [0.707, 0]
softmax([0.707, 0]) ≈ [0.670, 0.330]
v₁ = [2, 0], v₂ = [0, 4] → 두 좌표에 정보가 나뉘어 들어갑니다.
출력 = w₁[2, 0] + w₂[0, 4] ≈ [1.340, 1.321]
표시된 가중치(0.330)로 손계산하면 두 번째 좌표는 1.320입니다 (반올림 시점 차이).

행렬 크기 · 한 헤드의 추적
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
단계  -  계산  -  출력 크기  -  한 행의 의미
점수  -  QKᵀ / √d_k  -  T×T  -  모든 Key와 비교
가중치  -  행별 softmax  -  T×T  -  허용 위치의 합 = 1
출력  -  가중치 × V  -  T×d_v  -  Value의 가중합
T: 토큰 수 / d_k: Key의 차원 / d_v: Value의 차원

위치 정보 · Causal mask
순서를 알려 주는 것과 미래를 가리는 것은 어떻게 다를까? (다음 토큰 예측 중 ‘컵을’까지 읽은 상황)

빨간 (첫 번째 위치)  →  컵을 (두 번째 위치 · 현재)  →  집어 (세 번째 위치 · 미래 · 가림)

위치 정보: ‘컵을’이 두 번째라는 단서를 제공
Causal mask: ‘집어’를 참고할 비율을 0으로 만듦
학습 시에는 정답까지 한 문장에 들어 있으므로, 미래 위치를 가려야 실제 생성 때와 같은 조건에서 연습합니다.

Attention 종류 · 참고 범위
방식  -  Query  -  Key · Value  -  참고 범위
양방향 self  -  입력 토큰  -  같은 입력  -  앞뒤 토큰
Causal self  -  생성 중 토큰  -  같은 시퀀스  -  현재와 과거
Cross  -  디코더 상태  -  인코더 출력  -  다른 입력의 위치
위치 정보는 토큰의 순서를 담고, 마스크는 참고할 수 있는 범위를 정합니다.

헤드와 블록 · 역할 구분
헤드(head): 자기만의 Wq·Wk·Wv로 Attention을 한 번 계산하는 단위

여러 헤드 (각자 토큰 관계 계산)  →  결합 (결과를 이어 붙여 변환)  →  FFN · 신경망 (각 토큰의 특징 가공)

여러 헤드는 같은 문장에서도 서로 다른 관계를 학습할 수 있으며, 블록은 이런 계산을 묶은 반복 단위입니다.
잔차 연결: 입력을 결과에 다시 더해 이전 정보를 전달
정규화: 특징값의 크기를 조절해 학습을 도움

Multi-head Attention · 블록 구성
각 헤드는 고유한 Q·K·V 투영으로 가중합을 계산하고, 헤드들의 출력을 이어 붙여 선형층에 통과시킵니다.
하위층  -  역할  -  동작
Attention  -  토큰 사이의 정보 결합  -  헤드별 가중합 → 결합
FFN  -  위치별 특징 변환  -  같은 FFN을 각 위치에 적용
잔차 연결: 각 하위층의 입력을 출력에 더함 / LayerNorm: 특징의 크기를 조절

KV cache · 긴 입력에서 줄이는 계산
길이 T인 입력의 점수 행렬에는 T²개 원소가 있으며, 토큰 수를 두 배로 늘리면 점수 개수는 네 배가 됩니다.
단계  -  동작
첫 입력 처리  -  과거 토큰의 K·V를 층별로 저장
다음 토큰 생성  -  새 Q로 기존 K와 비교 · 새 K·V를 캐시에 추가
KV cache는 이전 위치의 Key·Value 계산을 재사용하지만, 새 토큰이 참고할 과거 위치와 캐시 메모리는 계속 늘어납니다.
예: 토큰 128개 → 256개일 때 점수 개수 16,384개 → 65,536개 (한 헤드가 전체 입력을 한 번에 비교하는 경우)

실습 ① · Query와 마스크 바꿔 보기
손계산 예제의 두 Key(k₁ = [1, 0], k₂ = [0, 1])와 Value(v₁ = [2, 0], v₂ = [0, 4])를 그대로 사용합니다.
조건  -  설정
기본 Query  -  q = [1, 0]
Query 교체  -  q = [0, 1]
둘째 Key 차단  -  가중치 [1, 0]
예상 결과: Query를 바꾸면 둘째 Value의 가중치는 약 0.670 / 둘째 위치를 가리면 첫째 Value만 남아 출력은 [2, 0]
모든 조건에서 가중치 합이 1인지 확인하고, 소수 셋째 자리에서 값이 다르면 반올림 시점을 비교합니다.
```python
import numpy as np

def attention(q, K, V, mask=None):
    s = K @ q / np.sqrt(len(q))
    if mask is not None:
        s = np.where(mask, s, -np.inf)
    w = np.exp(s - s.max()); w /= w.sum()
    return w, w @ V

K = np.array([[1, 0], [0, 1]]); V = np.array([[2, 0], [0, 4]])
print(attention(np.array([1, 0]), K, V))                         # [0.670 0.330] [1.340 1.321]
print(attention(np.array([0, 1]), K, V))                         # [0.330 0.670] [0.660 2.679]
print(attention(np.array([1, 0]), K, V, np.array([True, False])))  # [1. 0.] [2. 0.]
```

실습 ② · 세 토큰의 causal Attention
Q = K = [[1, 0], [0, 1], [1, 1]]
V = [[1, 0], [0, 2], [3, 3]], d_k = 2
Query  -  허용 Key
첫째 Query  -  Key 1만 허용
둘째 Query  -  Key 1, 2 허용
셋째 Query  -  모든 Key 허용
첫 토큰은 자기 자신만 참고하므로 출력이 [1, 0]입니다.
마스크를 풀고 첫 출력에 미래 Value가 섞이는지 비교합니다.
```python
import numpy as np

Q = K = np.array([[1, 0], [0, 1], [1, 1]], dtype=float)
V = np.array([[1, 0], [0, 2], [3, 3]], dtype=float)
S = Q @ K.T / np.sqrt(2)
S = np.where(np.tril(np.ones((3, 3), bool)), S, -np.inf)   # causal mask
W = np.exp(S - S.max(1, keepdims=True)); W /= W.sum(1, keepdims=True)
print(W.sum(1))   # [1. 1. 1.]
print(W @ V)      # 첫 행 [1. 0.]
```

질문  -  핵심
점수 조정  -  무엇으로 나눌까?

입력의 출처  -  Q·K·V가 같은 입력이면?
가중치의 합이 1인 이유를 softmax 식으로 설명하고, 둘째 위치를 가리기 전후의 출력 좌표를 비교합니다.
질문할 때는 사용한 입력값과 막힌 계산 단계를 함께 제시합니다.
