




### 1. 쿼터니언이란 — 축과 각으로 회전을 적다
   오일러의 회전 정리에 따르면, 어떤 3D 회전이든 하나의 축 $\mathbf{n}$ 을 중심으로 각 $\theta$ 만큼 도는 것으로 표현할 수 있습니다. 쿼터니언은 바로 이 (축, 각)을 4개 숫자로 인코딩합니다.
   
   **복소수 - 회전을 담는 수**   ![[Pasted image 20260821090113.png]]
   이 구조를 3차원 회전으로 확장한 4원수 (w, x, y, z) 가 쿼터니언입니다.
   
   **복소수 곱 = 2D 회전**
   크기 1인 복소수를 곱하면 복소평면에서 각 θ 만큼 회전합니다 — 고교 복소수가 이미 '회전을 담는 수'였습니다.
   이 아이디어를 3차원으로 확장하려면 숫자가 4개 필요하다는 것이 해밀턴의 발견입니다.   ![[Pasted image 20260821090208.png]]
   
   **쿼터니언 = 회전축 + 회전각**
   오일러 회전 정리: 어떤 3D 회전이든 '축 하나 + 각 하나'로 표현됩니다. 쿼터니언은 그 (축, 각)의 인코딩입니다.
   스칼라부 w 가 '얼마나', 벡터부 (x,y,z) 가 '어느 축으로'를 담습니다. 회전 쿼터니언은 항상 크기 1입니다.
   ![[Pasted image 20260821090546.png]]
   ![[Pasted image 20260821090603.png]]
   반각 θ/2 덕분에 쿼터니언 곱이 회전 합성과 정확히 맞아떨어집니다.
   
   
### 2. 왜 쿼터니언인가 — 세 가지 강점
   * 짐벌락 없음: 축-각 표현이라 특정 각도에서 자유도가 붕괴하는 일이 없습니다(18강 문제 해결).
   * 가벼움과 안정성: 4숫자(회전행렬은 9)로 표현하고, 반복 계산 후 크기를 1로 정규화만 하면 다시 유효한 회전이 됩니다. 회전행렬의 Gram-Schmidt 재직교화(18강)보다 훨씬 간단합니다.
   * 부드러운 보간: 두 자세 사이를 일정한 각속도로 잇는 SLERP가 가능합니다(4절).
   - 중요: 오일러 각은 사람이 읽을 때, 회전행렬은 좌표를 변환할 때, 쿼터니언은 저장·통신·보간할 때 씁니다. 세 표현은 자유롭게 오가며, 상황마다 최적의 그릇을 고르는 것이 로보틱스의 실무 감각입니다.
   
   
### 3. 쿼터니언 ↔ 회전행렬 변환
   **쿼터니언 ↔ 회전행렬**
   쿼터니언으로 저장·보간하다가 좌표를 실제로 변환할 때는 이 공식으로 회전행렬을 만듭니다.
   외울 필요는 없습니다 — '둘은 같은 회전의 다른 표현'이라는 개념이 핵심입니다.
   단위 쿼터니언 q=(w,x,y,z) 에서 회전행렬은 다음으로 구합니다.   ![[Pasted image 20260821092117.png]]
   
   **축-각 -> 쿼터니언 - 숫자로**
   z축을 중심으로 90° 도는 회전을 쿼터니언으로 적습니다.   ![[Pasted image 20260821103317.png]]
   
   
### 4. SLERP — 자세를 부드럽게 잇다
   **SLERP 공식**
   로봇 팔을 자세 A에서 자세 B로 움직인다고 합시다. 중간 자세들을 어떻게 만들까요? 두 쿼터니언을 그냥 선형으로 섞으면(각 성분 평균) 회전이 일정하지 않고, 중간에 크기가 1을 벗어나 회전 속도가 요동칩니다.
   SLERP 는 구면 위 최단 호를 일정한 각속도로 따라갑니다 — 계수가 sin 비율인 이유입니다.   ![[Pasted image 20260821103936.png]]![[Pasted image 20260821104125.png]]
   해석: SLERP(보라) 는 보간 파라미터 t 에 대해 회전이 일정한 비율로 진행됩니다 — 매끄럽고 예측 가능한 움직임. 반면 성분을 그냥 선형으로 섞어 정규화하면(회색 점선, NLERP) 중간에서 각속도가 빨라졌다 느려져 움직임이 고르지 않습니다. 로봇 팔이나 카메라를 자연스럽게 움직이려면 SLERP가 필요합니다.
   
   **SLERP vs NLERP - case 비교**
   왼쪽: 회전각의 진행 — SLERP 는 직선(등속), NLERP 는 S자(중간에서 빨라졌다 느려짐).
   오른쪽: 호 위의 중간 자세 11개 — SLERP 는 등간격, NLERP 는 중앙에 몰립니다.   ![[Pasted image 20260821104747.png]]
   
   **SLERP 중간 자세 - 숫자로**
   항등 자세와 z축 90° 자세 사이를 t = 0.5 로 보간하면 45° 회전이 나와야 합니다.   ![[Pasted image 20260821105049.png]]
   
   
### 5. 고유값과 고유벡터 — 방향이 보존되는 특별한 벡터
   **이차방정식 - 근의 공식과 근, 계수 관계**   ![[Pasted image 20260821112219.png]]
   특성방정식의 근이 고유값 — 근·계수 관계가 tr·det 검산식이 됩니다.
   ㅁ
   
   **방향이 보존되는 특별한 벡터**
   일반 벡터는 A 를 곱하면 방향이 돌아가지만, 고유벡터는 방향이 유지되고 크기만 λ배 됩니다.
   '변환이 건드리지 못하는 방향'이 시스템의 본질적 성질을 드러냅니다 — 공진, 안정성, PCA 의 뿌리.
   ![[Pasted image 20260821112405.png]]![[Pasted image 20260821112422.png]]
   
   **특성방정식 유도**
   Av = λv 를 이항하면 (A−λI)v = 0. v ≠ 0 인 해가 존재하려면 A−λI 가 특이해야 합니다.
   특이 = 행렬식 0 (18강) — 그래서 고유값은 다항방정식의 근으로 구해집니다.   ![[Pasted image 20260821112617.png]]
   
   **고유값, 고유벡터 - 숫자로 풀기**
   2×2 행렬의 특성방정식을 세우고, 근·계수 관계로 검산까지 합니다.   ![[Pasted image 20260821112732.png]]
   ![[Pasted image 20260821112744.png]]
   ㅁ
   **회전행렬의 회전축과 회전각 - 유도**
   회전축 위의 벡터는 회전해도 그대로: Rn = n, 즉 λ=1 인 고유벡터가 곧 회전축입니다.
   대각합은 고유값의 합이므로 tr R = 1 + 2cosθ — 회전각이 대각합에서 바로 나옵니다.   ![[Pasted image 20260821113002.png]]
