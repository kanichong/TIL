병렬 환경과 텐서

관측 shape: (환경 수, 관측 차원)
환경별 상태와 리셋을 구분
환경 수는 메모리를 보며 증가

물리 주기와 정책 주기
physics dt — 0.005 s — 물리 200 Hz
decimation — 4 — 정책 한 번에 물리 4회
policy dt — 0.005 × 4 = 0.02 s — 정책 50 Hz
episode time — 10 s — 정책 스텝 약 500회

배치 정책의 실행 흐름
```
obs = reset_all()          # 초기 관측
while running:             # 실행 반복
  actions = policy(obs)    # 환경별 행동
  obs = step_all(actions)  # 물리 센서 갱신
  reset_finished_envs()    # 끝난 환경 리셋
```

학습 전에 통과해야 할 검사

평가 조건을 별도로 준비

도메인 랜덤화의 생각
![[2026-10-21_17-20-07.png]]

범위를 바꿨을 때의 가설
너무 좁음 — 평가 조건을 충분히 경험하지 못함 — 조건별 성공률

너무 넓음 — 불가능한 과제·학습 난도 증가 — 실패 사유·학습 안정성
