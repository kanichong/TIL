


미분 노이즈 - 노이즈 증폭: 작은 측정 흔들림을 미분
원인 - 측정값 y에 포함된 노이즈.
영향 - r이 dr/dt=0 이더라도 dy/dt가 흔들림
해결법 - 목표가 가만히 있어도 흔들림, 미분 제어기 앞에 저역통과필터(LPF) 장착

미분킥
원인 - 목표값 r의 급격한 변화. 
영향 - dr/dt값이 순간적으로 폭발.
해결법 - 미분 제어기에  -y 입력하도록 


du/dt 항상 연속적이다, 계단식 불가
D의 축력 = Kd x (-dy/dt)

저주파 - 고주파 신호를 없애고 느리게 움직이는 신호.(고주파를 지우는 필터)

실무 D항: 측정값 미분과 필터
D 입력에 -dy/dt를 사용합니다.
필터를 강하게 걸면 지연도 늘어납니다

MCU에서는 일정 주기로 계산
물리단위 0.001s
PID  dt는 0.001을 사용


장치동역학 - 제어하려는 대상이 얼마나 빠른가
센서 성능 - 센서가 측정할 수 없는 시간 , 로봇 최대 이동속도
계산 시간 - 계산 시간 (PID 제어기의 계산 시간), dt 주기는 반드시 제어기보다 길어야함, 제어기 연산시간이 주기보다 빨라야 함.

Kp=2
Ki=1
Kd=0.05
dt=0.1s
이전 적분 누적값=0.4
이전오차pre e=2
현재오차e=1
제어출력한계=+-1

적분 = 0.4 + 1*1*0.1 = 0.5
미분 = 0.05 * (1-2/0.1) = 0.05*-10 = -0.5
u = P(Kp*e) + I(0.5) + D(-0.5) = 2+0.5-0.5 = 2


적분결과 -> A=0.4+1*0.1=0.5
미분결과 -> D=(1-2)/0.1=-10
최종제어출력 -> u=2+0.5-0.5=2.0

한계가 +-1 일때 출력은?
출력할 수 없다 --> 한계가 +-1인데 계산된 출력은 2

D항의 부호가 음수인 이유는?
현재오차가 1이고 이전오차가 2이기때문에 1-2 = -1, 그래서 미분값은 -1/0.1 = -10, -10 * Kd(0.05) --> -0.5
오차가 줄어들고 있기 때문에 제어출력을 줄여줍니다.

댐핑 역할
미분치 D = (현재오차 - 이전오차)/샘플링시간
