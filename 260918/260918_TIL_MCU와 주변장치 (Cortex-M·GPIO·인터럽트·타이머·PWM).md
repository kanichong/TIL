

주변장치, 레지스터, 폴링, 인터럽트, 제어주기, PSC, PWM, 모터드라아버

아두이노 우노, 메가
공식문서 확인 필수(schmetic)

SBC(single board computer) - 영상 처리, 인식, 상위 계획 (운영체제 설치)
MCU - 센서 획득, 주기 제어, 구동 신호 (운영체제 설치 안됨)(RTOS)
실시간성은 응답 시간의 상한을 관리하는 문제입니다.

Flash: 프로그램과 상수, 전원 없이 보존
SRAM: 실행 중 변수와 스택

GPIO의 네 가지 모드
입력: 버튼, 상태 신호 읽기
출력: LED, 드라이버 방향 신호
대체 기능: 타이머, UART / 아날로그: ADC 등

버튼 입력과 풀업
풀업: 버튼을 놓으면 High
버튼으로 GND에 연결하면 LOW
떠 있는 입력은 안정적인 논리값을 보장하지 않는다.

버튼 바운스
한 번 눌러도 접점이 여러 번 변할 수 있습니다.
안정된 상태를 확인한 뒤 한 번의 입력으로 처리
판정 시간은 실제 스위치 특성에 맞춰 정합니다.

인터럽트의 처리 흐름
주변장치가 이벤트와 요청을 발생시킵니다.
NVIC가 우선순위에 따라 CPU 처리를 중재합니다.
ISR을 마치면 중단했던 코드로 돌아갑니다.

타이머의 카운터
입력 클럭을 PSC로 분주합니다.
CNT

PWM의 주기와 듀티
빠르게 껐다 켰다 하면서 켜져 있는 시간의 비율을 조절합니다. 이것이 PWM(Pulse Width Modulation, 펄스 폭 변조) 입니다.
PWM: 듀티 사이클과 푱균 전압
