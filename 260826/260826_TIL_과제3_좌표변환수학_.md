****Ubuntu / Debian**** — 시스템 파이썬에 `pip`·`venv` 모듈이 빠져 있는 경우가 많습니다.  
  
```bash  
sudo apt update  
sudo apt install -y python3-venv python3-pip  
  
# 설치 확인  
python3 -m pip --version  
python3 -m venv --help  
```  
  
****macOS**** — Homebrew로 설치하면 pip·venv가 함께 따라옵니다.  
  
```bash  
brew install python3  
```  
  
****Windows**** — [[python.org](http://python.org)](https://www.python.org/downloads/) 설치 파일 실행 시 ****"Add python.exe to PATH"**** 체크박스를 반드시 켜세요. 이후 `python`, `pip` 명령을 그대로 쓸 수 있습니다.
