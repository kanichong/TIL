

지연 + 큰 보정 --> 발진

입력과 출력이 유한한 범위에 머문다 --> BIBO 안정

안정 - 진폭이 줄고 목표값에 수렴
한계안정 - 일정한  진폭으로 끊임없이 진동 (센서의 노이즈, 모터의 노이즈, 적분 오차... 등등)
불안정 - 진폭이 커지거나 값이 끊임없이 증가

극점 : 전달함수의 분모를 0으로 만드는 S값이 시스템의 운명을 결정. 그 값이 극점.
모든 극점이 실수부 < 0  ==  안정
극점이 허수 축 위  == 한계안정 가능
하나라도 실수부 > 0  ==  불안정

a = 실수부 --> 신호의 진폭  -->  양수면 진폭 / 음수면 0 에 수렴
t = 시간
